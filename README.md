# Trading Assistant

Full-time automated trading assistance stack.

## Stack

- Windmill — orchestration, scripts, flows, frontend
- Steel Browser — virtual browser / session management / crawler
- PostgreSQL — Windmill metadata database
- Neo4j — knowledge graph
- Caddy — reverse proxy
- Local LLM — Ollama / Hugging Face
- Telegram — alerts
